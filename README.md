# VacumCite

**VacumCite** es un diseño de sitio web intuitivo y accesible para facilitar la reserva de citas de vacunación contra el COVID-19.

**Detalles del Proyecto Académico:**
- **Grado**: Ingeniería de Software
- **Universidad**: U-tad
- **Asignatura**: Fundamentos de UX

Prioriza una experiencia de usuario simple, con navegación clara y formularios amigables para buscar centros de vacunación, seleccionar fechas y confirmar citas.

## Características Principales
- Búsqueda de centros cercanos por ubicación o código postal.
- Calendario interactivo para disponibilidad de vacunas (Pfizer, Moderna, etc.).
- Formulario de registro rápido con validación en tiempo real.
- Confirmación por email/SMS y recordatorios automáticos.
- Diseño responsive para móvil y desktop.

## Lecciones Aprendidas
- Enfoque en accesibilidad y usabilidad para audiencias diversas.
- Iteraciones basadas en pruebas de usuario simuladas.
